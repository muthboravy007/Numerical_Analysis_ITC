Every numerical answer is reproduced by [`code/verify_exams.py`](code/verify_exams.py). Run `python assessments/code/verify_exams.py`.

These are *practice* papers: they show the format, the length and the balance of the real exams. That balance is about 40% hand computation, 30% theory and proof, and 30% interpretation and data-science reasoning. Instructors should write fresh papers each year. Adapting the numbers in the verification script is the quickest way to do so.
